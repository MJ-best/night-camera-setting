# 밤하늘 촬영 플래너 (night-camera-setting)

은하수·달·별궤적·유성우·행성·도시 야경을 찍을 때 필요한 **카메라 설정**, **카메라를 둘 방향**, **그날 밤 하늘**을 한 화면에서 보여 주는 웹앱입니다. 빌드 과정 없는 정적 사이트라 GitHub Pages 같은 곳에 그대로 올리면 됩니다.

## 무엇을 알려 주나

| 대상 | 카메라 설정 | 방향 · 시간 |
| --- | --- | --- |
| 은하수 | NPF 규칙으로 별이 점으로 남는 최대 셔터, 하늘 밝기(광해·달빛·박명)에 맞춘 ISO, 500 법칙·트래커 대안 | 오늘 밤 가장 좋은 은하수 영역(중심부·방패자리·백조자리·겨울 은하수 등)과 방위·고도, 세로/가로 구도 |
| 달 | 위상각·고도(대기 감광)로 보정한 Looney 11 노출, 일주운동 번짐 한계, 프레임 속 달 크기 | 월출·월몰 시각과 방위, 가장 높이 뜨는 시각, 다음 보름·삭 |
| 별궤적 | 30초 인터벌 장 수·총 시간·궤적 길이, 벌브 대안 | 북극성(남반구는 천구 남극) 방향과 고도 |
| 유성우 | 짧은 노출 연속 촬영 설정 | 10개 주요 유성우의 극대 시각(태양황경 기준), 복사점 위치, 시간당 기대 개수 |
| 행성 | 광각(풍경)·망원(원반·목성 위성) 설정 | 행성별 잘 보이는 시각·방위·밝기·별자리 |
| 도시 야경 | 태양 고도별 장면 밝기, 빛갈라짐·차량 궤적 대안 | 골든아워·블루아워 시간표 |

공통으로 다음도 보여 줍니다.

- **GPS 위치**(또는 좌표 직접 입력, 장소 저장)와 **날짜**에 따른 일몰·박명·월출/월몰
- **하늘 지도**: 지평선 파노라마 / 전천 돔. 별자리, 은하수 띠, 달 위상, 행성, 은하 중심, 유성우 복사점, 지금 렌즈의 **화각 사각형**
- **오늘 밤 흐름** 차트: 천체 고도 곡선, 박명 음영, 촬영 적기 구간, 시간별 구름량
- **실시간 나침반**: 휴대폰을 돌리면 "오른쪽으로 32°"처럼 안내 (자기 편각 보정, 한국 기본 −8.5°)
- **앞으로 30일**: 은하수 좋은 날, 달 위상, 달 없는 어두운 시간
- **날씨**: [Open-Meteo](https://open-meteo.com) 구름량·습도·이슬점·바람 (16일 이내)
- **적색 · 녹색 모드**: 버튼을 누를 때마다 기본 → 적색 → 녹색 화면으로 바뀌어요. 적색이 눈의 암적응을 가장 잘 지키고, 녹색은 같은 밝기에서 글자가 더 잘 보여요
- **오프라인**: 한 번 열면 서비스 워커가 앱을 저장해 신호 없는 촬영지에서도 천문 계산이 됩니다

아래쪽 시간 막대를 움직이면 설정·방향·지도가 그 시각 기준으로 바뀝니다. "추천 시각"은 대상별로 가장 좋은 시각으로 돌아갑니다.

## 노출 계산 방식

- **목표 노출**: 보틀 등급별 달 없는 밤하늘 EV100(예: 보틀 3 → −6.3)에 달빛(달 등급·고도)과 박명 밝기를 더해 장면 EV를 구하고 `ISO = 100·N² / (t·2^EV)` 로 ISO를 정합니다.
- **NPF 규칙(간이식)**: `t = (35·N + 30·p) / f` (N 조리개, p 화소 피치 µm, f 초점거리 mm)
- **달**: 보름 EV100 13.8에서 위상각 45°마다 1스톱, 대기질량(Kasten–Young)에 따른 감광을 뺍니다.
- 밝은 렌즈(f/1.4 등)는 코마를 줄이려 한 스톱 조여 계산합니다.

결과는 **출발점**입니다. 현장에서 테스트 컷의 히스토그램을 보고 조정하세요.

## 실행

```bash
npm start          # python3 -m http.server 8080 → http://localhost:8080
npm test           # Node 22+ 내장 테스트 러너
```

ES 모듈을 쓰므로 `index.html`을 파일로 바로 열지 말고 로컬 서버로 여세요. GPS와 나침반은 **HTTPS**(또는 localhost)에서만 동작합니다.

## 배포 (GitHub Pages)

`.github/workflows/pages.yml`이 `main`에 푸시될 때 테스트 후 Pages로 배포합니다. 처음 한 번 저장소 **Settings → Pages → Build and deployment → Source**를 **GitHub Actions**로 바꿔 주세요.

## 구조

```
index.html            화면 구조
css/style.css         스타일 (다크 + 적색·녹색 모드)
js/app.js             상태·렌더링·이벤트
js/astro.js           천문 계산 (Astronomy Engine 래퍼, 은하수·유성우·행성 분석)
js/camera.js          카메라 설정 계산 (순수 함수)
js/skymap.js          캔버스 별지도
js/chart.js           밤 고도 차트 (SVG)
js/weather.js         Open-Meteo 예보
js/compass.js         DeviceOrientation 나침반
js/data.js            밝은 별·별자리 선·유성우·은하수 영역 데이터
vendor/               Astronomy Engine 2.1.19 (MIT, cosinekitty)
sw.js, manifest.webmanifest, icons/   PWA·오프라인
tests/                단위 테스트
```

## 한계

- 시각은 **기기의 시간대**로 표시합니다. 다른 시간대 지역을 계획할 때는 주의하세요.
- 자기 편각 기본값은 한국·일본 부근의 대략값입니다. 정확한 값은 NOAA 편각 계산기로 확인해 입력하세요.
- 별 데이터는 사진 계획용으로 밝은 별 위주(약 150개)입니다.
